# SwapWear – Clothing Exchange & Swap Marketplace

SwapWear is a frontend web application developed as part of my Frontend Developer Internship. It allows users to explore clothing listings, list their own clothes, save favorite items, and send swap requests.

## Technologies Used
- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Browser Local Storage

## Main Features
- User registration and login
- Browse and filter clothing listings
- Add and manage clothing listings
- Wishlist
- Clothing swap requests
- Chat interface
- User dashboard
- Notifications
- Admin interface
- Responsive frontend design

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL displayed in the terminal.
